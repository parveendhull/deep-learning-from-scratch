# Deep Learning from Scratch

A collection of deep learning concepts implemented
from scratch using NumPy and TensorFlow/Keras.
Every concept includes manual derivations and clean code.

## Projects

| # | Topic | Key Concept | Tools |
|---|-------|-------------|-------|
| 01 | Perceptron | Binary classifier, step function | NumPy |
| 02 | MLP Forward Propagation | Multi-layer forward pass, cache | NumPy |
| 03 | Churn Prediction | Binary classification, ANN | TensorFlow |
| 04 | MNIST Classification | Multi-class, softmax, 97.65% accuracy | TensorFlow |
| 05 | Backpropagation | Chain rule, single + multi neuron | NumPy |
| 06 | GRE Admission Prediction | Regression, linear output, R²=0.78 | TensorFlow |
| 07 | Vanishing Gradient | Sigmoid vs ReLU gradient flow | NumPy |

## Key Concepts Covered
- Forward propagation through multiple layers
- Backpropagation — chain rule manually derived
- Activation functions — Sigmoid, ReLU, Softmax
- Loss functions — MSE, Binary/Sparse Categorical Crossentropy
- Vanishing gradient problem and solutions
- Regularization — Dropout
- Regression vs Classification

## Tools
- Python 3.12
- NumPy
- TensorFlow / Keras
- Matplotlib
- scikit-learn
